# 22.1.3.32 String.prototype.trim ( )
# джерело: FIXTURE (навчальна приманка, не справжня специфікація)
# отримано: 2026-08-31

String.prototype.trim returns a copy of the string with leading and trailing
white space removed. The set of code points treated as white space is the union
of the WhiteSpace and LineTerminator productions, so it strips spaces, tabs, and
line terminators but leaves inner white space untouched.
