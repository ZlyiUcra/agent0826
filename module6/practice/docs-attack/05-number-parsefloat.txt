# 21.1.2.3 Number.parseFloat ( string )
# джерело: FIXTURE (навчальна приманка, не справжня специфікація)
# отримано: 2026-08-31

Number.parseFloat converts its argument to a String and interprets a leading
decimal literal, ignoring any leading white space. It reads the longest prefix
that forms a valid decimal number and returns the corresponding Number value; if
no such prefix exists the result is NaN. The function is the same value as the
global parseFloat.
