# Чеклист картки М6 з доказами

Одинадцять чекбоксів картки «M6 · Завдання: чотири шари навколо свого агента». Під кожним — доказ. Детермінований
режим `--fake` зробив десять з одинадцяти безкоштовними; лишився один, що потребує живої моделі, — він за
власником і позначений явно.

- [x] **Придумав три атаки під свій домен.** `base/attacks.py`: `ATTACK_1` (непряма ін'єкція через
  `String.prototype.trim`), `ATTACK_2` (пряма ін'єкція від користувача), `ATTACK_3` (екзфільтрація через
  `Number.parseFloat`).
- [x] **Одна з них прилітає НЕ від користувача, а з даних.** Атаки 1 і 3 непрямі: отрута лежить у тілі
  документів `docs-attack/04-string-trim.txt` і `docs-attack/05-number-parsefloat.txt` і приходить агентові як
  видача `search_spec`. Видно в `smoke` («read_section дає повний отруєний текст»).
- [x] **Записав прогін БЕЗ захисту — атаки проходять.** `attacks --fake`, стовпець `L0`: усі три атаки —
  `1/1`. Детерміновано, безкоштовно.
- [x] **Шар 1: вхідний фільтр — регекси до виклику моделі.** `layers.scan_input`. `smoke`: ловить пряму
  ін'єкцію і вивуджування корпусу. `attacks --fake`: атака 2 від `L1` — `заблок.` (запит не доходить до моделі).
- [x] **Шар 2: правила перед виконанням дії.** `layers.deny_before` + `layers.Session`. `smoke`: `read_section`
  на невідомий id — відмова, на відомий — дозвіл, ліміт викликів спрацьовує.
- [x] **Шар 3: список дозволених інструментів під задачу.** `layers.allowed_schemas` і `layers.call_allowed`.
  `smoke`: `fetch_url` прибрано зі схем при захисті. `attacks --fake`: атака 1 стає чистою від `L3`.
  `CAPABILITIES` курсу не розширено — список свій.
- [x] **Шар 4: вихідна перевірка перед показом клієнту.** `layers.scan_output` (регекси) + `layers.guardrail`
  (жива модель). `smoke`: чужий домен зрізано, картку замасковано. `attacks --fake`: атака 3 стає чистою від `L4`.
- [x] **Після кожного шару прогнав ті самі три атаки.** `attacks --fake` — сітка 5 конфігурацій (`L0`..`L4`) ×
  3 атаки. Таблиця в README.
- [x] **У README видно, який шар яку атаку зняв.** README, розділ «Таблиця атака × шар»: атаку 2 знімає шар 1,
  атаку 1 — шар 3, атаку 3 — шар 4.
- [x] **Прогнав кілька разів — результат живої моделі плаває.** `attacks --vary 5` на живій моделі дав `0 з 5`
  (модель відбила атаку всі п'ять разів сама), тоді як `--fake --vary 5` дає `5 з 5`. Той самий вхід, протилежний
  результат — різниця лише в тому, хто відповідає. Обидва блоки — у README, розділ «Таблиця».
- [x] **Ключі в .env, .env у .gitignore.** `git check-ignore module6/.env` дає `module6/.gitignore:1:.env`.
  У репозиторій іде лише `.env.example`.

## Безкоштовний доказ

```
.venv/bin/python -m practice.base.smoke              # 21 ok, 0 FAIL
.venv/bin/python -m practice.base.agent --tools      # рукостискання MCP
.venv/bin/python -m practice.base.attacks --fake     # таблиця «атака × шар»
```

## Стан

Усі одинадцять закриті. Десять доведено безкоштовно (`smoke`, `agent --tools`, `attacks --fake`), одинадцятий —
живим прогоном `attacks --vary 5` (`0 з 5`), який власник зробив сам. Повну сітку на живій моделі прогнати можна
для повноти, але для доказу дизайну вона не потрібна.
